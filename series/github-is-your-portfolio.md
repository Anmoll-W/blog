# Series: GitHub is Your Portfolio

How to use GitHub as a primary professional presence instead of a portfolio website.

This is not about having a clean commit history. It is about using the profile README and repository READMEs as case studies that tell the story of what you build, why you built it, and what you learned.

## Posts in This Series

1. [GitHub as Your Portfolio: Why I Archived a Full Portfolio Site for a README](../posts/2026-04-08-github-as-your-portfolio.md)
   The strategic decision to retire a React portfolio site with real interactive tools and replace it with a well-crafted GitHub presence. Covers why two presences split focus, what a real GitHub portfolio requires, and how the tool stack you list is a positioning statement.
